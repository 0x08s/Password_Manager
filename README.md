# 🔐 C++ Password Manager

A simple **Password Manager** built with **C++** 💻🔒

This project allows users to securely manage their saved account information through a simple menu-driven system. It includes features for **adding, viewing, searching, updating, and deleting passwords** using C++ file handling. 📁✨

### 🚀 Features

* ➕ Add New Password
* 👀 View All Passwords
* 🔍 Search Password
* 🔄 Update Password
* 🗑️ Delete Password
* 🚪 Exit
* 📂 File Handling with C++

### 🛠️ Technologies

* 💻 C++
* 📁 File Handling
* 🧠 Basic Programming Concepts

This project is created for **learning and practicing C++ file handling and CRUD operations**. 🌱🚀
